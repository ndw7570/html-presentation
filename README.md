# 발표 게시판 (HTML Deck Board)

문서 목록은 [`TOC.md`](TOC.md) 에 있다.

AI 가 만들어 준 단일 HTML 파일을 끌어다 놓으면 바로 목록에 올라가고, 그 자리에서 전체화면으로
발표할 수 있는 사내용 게시판. 파일을 주고받는 대신 **주소 하나를 공유**하는 것이 목적이다.

## 두 개의 주소

| 주소 | 누가 여나 | 할 수 있는 것 |
|---|---|---|
| `/` | **로그인한 사람만** | 올리기·고치기·지우기·폴더 정리·발표 — **쓰기 가능** |
| `/s/<token>` | **아무나** | 발표 **하나** — 읽기 전용 |
| `/f/<token>` | **아무나** | 폴더 **하나와 그 하위 전부** — 읽기 전용 |

로그인 없이는 게시판 화면도, 목록 API 도, 내부 주소 `/p/<id>` 도 열리지 않는다.
공유 주소는 **링크를 아는 사람만** 보는 방식이다. 검색엔진에는 `noindex` 로 막아 두었다.

## 빠르게 돌려 보기

```bash
npm install
npm run adduser    # 계정 만들기 (처음 한 번). 비밀번호는 화면에 안 찍힌다
npm start          # http://localhost:4300
npm run dev        # 코드 고치면 자동 재시작 (node --watch)
```

브라우저를 열고 `.html` · `.md` · `.pdf` 를 **화면 아무 데나** 끌어다 놓으면 끝이다.

> Windows PowerShell 5.1 에서는 `npm install && npm start` 가 안 된다. `&&` 를 문 구분자로
> 치지 않는 버전이다. 두 줄로 나눠 치거나 `npm install; npm start` 로 친다.

## 쓰는 법

| 하려는 것 | 방법 |
|---|---|
| 발표 올리기 | 화면에 `.html` · `.md` · `.pdf` 드롭 (여러 개 동시 가능) 또는 `N` 키 |
| 주제 폴더 만들기 | 사이드바 `＋ 폴더` (맨 위에 생긴다) |
| 하위 폴더 만들기 | 폴더의 `···` → 하위 폴더 추가 |
| 폴더에 넣기 | 툴바의 폴더 선택 상자를 바꾸거나, 목록에서 글을 폴더 이름 위로 끌어다 놓기 |
| 폴더 옮기기 | 폴더 이름을 다른 폴더 **이름 한가운데**로 끌어다 놓기. `···` → 맨 위로 빼기 |
| 차례 바꾸기 | 항목을 다른 항목의 **위아래 가장자리**로 끌어다 놓기. 파란 선이 들어갈 자리다 |
| 폴더 이름/삭제 | 폴더 이름 위에 마우스를 올리면 나오는 `···` |
| 발표하기 | `발표하기` 버튼 또는 `F` 키 → 전체화면. `Esc` 로 나감 |
| 발표 하나 보내기 | `공유 링크 복사` → `http://서버/s/<token>`. **로그인 없이 열린다** |
| 폴더째 보내기 | 폴더의 `···` → `폴더 공유 켜기` → `http://서버/f/<token>` |
| 공유 끄기 / 새 주소 발급 | 글은 `···`, 폴더도 `···` |
| 계정 추가 / 비밀번호 변경 | 사이드바 아래 `계정` |
| 제목 바꾸기 | `···` → 제목 바꾸기 |
| 같은 글 내용만 교체 | `···` → 새 버전 올리기 (주소가 유지되므로 이미 보낸 링크가 안 깨진다) |
| 검색 | `/` 키 |
| 홈 (올리는 화면으로) | 왼쪽 위 `▶ 발표 게시판` 누르기 |
| 발표자 노트 | 툴바 `메모`. 자동 저장된다 |

제목은 올린 파일의 `<title>` → 첫 `<h1>` → 파일 이름 순으로 자동으로 정해진다.

### 끌어 놓기 — 안으로 넣기와 사이에 끼우기

같은 화면에서 두 가지를 한다. **놓는 자리**로 가른다.

| 끄는 것 | 놓는 곳 | 무슨 일 | 표시 |
|---|---|---|---|
| 발표 | **폴더 이름** (어디든) | 그 폴더로 옮긴다. `미분류` 도 같다 | 테두리가 파랗게 |
| 발표 | 다른 **발표** | 그 자리에 끼워 넣는다(차례 변경) | 파란 **선** |
| 폴더 | 폴더 이름 **한가운데** | 그 폴더 **안으로** | 테두리가 파랗게 |
| 폴더 | 폴더 이름 **위아래 가장자리** | 그 자리에 끼워 넣는다 | 파란 **선** |

발표는 폴더 안에 사는 것이라 폴더 이름과 차례를 다툴 일이 없다. 그래서 폴더 이름 위에
놓으면 **어디에 놓든** 그 폴더로 옮겨진다. 다른 폴더에서 끌어 온 발표는 **옮기고 나서**
그 자리의 차례를 매긴다.

차례는 저장된다. 새로 올린 발표는 맨 위로 간다.

### 폴더 규칙

- **폴더 안에 폴더를 만들 수 있다. 최대 5단.** 사이드바 폭(272px)이 한계를 정한다
- 글은 **폴더 하나에만** 속한다. 어디에도 안 넣은 글은 `미분류` 에 모인다
- 새로 올리는 발표는 **마지막으로 누른 폴더**로 들어간다. 드롭할 때 오버레이에 표시된다
- 개수 배지의 `2+1` 은 **이 폴더에 직접 든 발표 2개 + 하위 폴더 1개** 라는 뜻이다
- 폴더를 **자기 자신이나 자기 하위 폴더 안으로** 옮길 수 없다 (서버가 막는다)
- 자손을 데리고 옮길 때도 **가장 깊은 자손이 5단을 넘으면** 막힌다

**폴더를 지워도 발표는 지워지지 않는다.** 하위 폴더와 안에 있던 발표는 *지운 폴더의 부모*로
한 단 올라간다. 맨 위 폴더를 지우면 미분류로 간다. 확인 창에 몇 개가 어디로 옮겨지는지 나온다.

## 설정

모두 환경변수. 전부 선택이다.

| 변수 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | `4300` | 포트 |
| `HOST` | `0.0.0.0` | 바인딩 주소 |
| `DATA_DIR` | `./data` | 저장 위치 |
| `MAX_UPLOAD` | `50mb` | 파일 한 개 크기 한도 |
| `ADMIN_USER` / `ADMIN_PASSWORD` | 없음 | 첫 계정을 **자동으로** 만든다 (도커용). 손으로 만들 때는 `npm run adduser` |
| `SECURE_COOKIE` | `0` | HTTPS 뒤에 둘 때 `1`. 세션 쿠키가 평문으로 안 나간다 |
| `SESSION_SECRET` | 자동 생성 | 비워 두면 `data/session-secret` 에 만들어 둔다 |

비밀번호는 소스에 적지 말고 실행 환경(systemd `Environment=`, `.env` 파일 등)에만 둔다.

## 저장 구조

```
data/
  index.json        폴더 목록 + 글 목록 (사람이 읽고 고칠 수 있는 형식)
  users.json        계정 (비밀번호는 해시로만)
  session-secret    세션 서명 열쇠
  posts/<id>.html   올린 원본 그대로
  posts/<id>.md     마크다운도 원본 그대로
  posts/<id>.pdf    PDF·SVG·PNG·drawio 도 원본 그대로
  state/<id>.json   그 자료가 스스로 저장한 상태 (체크 표시, 지도 핀 …)
```

```jsonc
{
  "folders": [{ "id": "6d2f41231d", "name": "제품 기획", "createdAt": "..." }],
  "posts":   [{ "id": "4cffefbde3", "title": "2026 Q1 로드맵",
                "folderId": "6d2f41231d", "createdAt": "...", "bytes": 342 }]
}
```

`folderId` 가 `null` 이면 미분류다. 폴더가 없던 시절의 `index.json` 도 그대로 열린다 —
서버가 뜰 때 `folders: []` 와 `folderId: null` 을 채워 넣는다.

DB 가 없다. `data/` 폴더를 통째로 복사하면 다른 서버로 그대로 옮겨진다. 백업도 이 폴더만 뜨면 된다.

### 같은 `data/` 를 두 프로세스가 볼 때

`index.json` 과 `users.json` 은 **파일이 바뀌었을 때만** 다시 읽는다(`mtime` 비교).
목록은 요청마다 한 번, 계정은 쓰기 전에 맞춘다. 그래서 서버를 켜 둔 채로 `npm run adduser`
를 돌리거나 컨테이너를 두 개 띄워도 서로의 변경이 지워지지 않는다.

다만 **맞춘 뒤 쓰기까지의 아주 짧은 틈**은 남는다. 두 프로세스가 같은 순간에 같은 글을
고치면 늦게 쓴 쪽이 이긴다. 쓰기가 잦아지면 이 틈이 보이기 시작하므로, 그때가
PostgreSQL 로 옮길 때다 — 파일 잠금으로 더 버티는 것은 권하지 않는다.

## 마크다운 (`.md`)

마크다운은 **보여줄 때** HTML 로 바꾼다. 원본 `.md` 가 그대로 저장되므로 내려받으면
올린 파일이 나오고, 렌더러를 고치면 이미 올린 글에도 바로 먹는다.

**빈 줄 뒤에 홀로 선 `---` 가 있으면 슬라이드**, 없으면 스크롤 문서가 된다.

````markdown
---
author: 남덕우      ← YAML 머리말은 발표에 안 나온다
---

# 첫 장

본문

---

## 둘째 장
````

- 슬라이드 조작: `→ ↓ Space Enter` 다음 · `← ↑ Backspace` 이전 · `Home/End` 처음·끝 ·
  화면 오른쪽/왼쪽 절반 클릭. 오른쪽 아래에 `1 / 3` 이 뜬다
- 주소 끝의 `#2` 로 특정 장을 바로 연다
- 글 밑줄로 쓴 `---`(Setext 제목)는 **자르지 않는다.** 앞에 빈 줄이 있어야 구분선으로 본다
- 제목은 첫 `# 제목` → 파일 이름 순
- 슬라이드 기능은 **외부 라이브러리를 안 쓴다.** 인터넷이 없는 사내망에서도 그대로 돈다

## 발표 자료의 인터랙션과 저장

체크박스·탭·폼·캔버스 같은 **DOM 인터랙션은 그냥 된다.** 격리는 저장만 막는다.

자료가 `localStorage` 에 넣는 값은 **서버에 저장된다.** 올리는 쪽은 아무것도 안 해도 된다 —
AI 에게 "체크 상태를 localStorage 에 저장해줘" 라고만 하면 그게 서버에 쌓인다.

원리: 격리된 문서에서는 `localStorage` 를 건드리기만 해도 SecurityError 가 난다.
그래서 **`localStorage` 를 우리 것으로 갈아 끼운다**(`lib/bridge.js`). 읽기는 그릴 때 박아 넣은
값에서 바로 주고(동기 API 라 나중에 받아올 수 없다), 쓰기는 `postMessage` 로 부모에게 넘겨
`PUT /api/state/:id` 로 저장한다.

| | |
|---|---|
| 저장 위치 | `data/state/<글id>.json` — 글마다 따로 |
| 한도 | 글당 256KB |
| **공유 주소에서는 저장 안 됨** | `/s/`, `/f/` 는 읽기 전용이라 상태를 쓰지 못한다. 저장된 값을 **보기는** 한다 |
| `sessionStorage` | 메모리로만 흉내낸다. 새로 고치면 사라진다 |
| `indexedDB` · 쿠키 · 서비스워커 | **쓸 수 없다.** 손대면 경고를 띄운다 |

### 저장 진단

올릴 때 자료가 쓰는 저장 수단을 훑어 둔다. 못 쓰는 것을 쓰면 글을 열 때 **노란 경고 띠**가
뜬다. 실행 중에 `indexedDB` 나 쿠키를 건드려도 그 자리에서 알린다.

> 정규식으로 훑는 것이라 완벽하지 않다 — 문자열 안의 단어도 잡고, 동적으로 만든 이름은
> 놓친다. "확실한 진단" 이 아니라 "한 번 보라는 신호" 로 쓴다.

## API 토큰 — AI 가 직접 올리기

사람 없이 올리려면 토큰을 쓴다. **`/tokens` 페이지**에서 발급한다.
게시판 왼쪽 아래 `API 토큰`, 또는 올리는 화면의 안내 줄에서 바로 간다.

- **발급할 때 한 번만 보인다.** 서버도 해시만 들고 있어 다시 꺼낼 수 없다
- 유효 기간을 고른다 — 1일 / 7일(기본) / 30일 / 만료 없음. 지난 토큰은 바로 막힌다
- 용도(`label`)는 **안 적어도 된다.** 비우면 `이름 없는 토큰` 이 된다
- 발급 화면에 **AI 에게 통째로 붙여 넣을 문구**가 같이 나온다. 주소·토큰·본문 모양·
  지금 있는 폴더·**자료 작성 규칙**이 들어 있어, 복사해서 그대로 주면 된다

### AI 에게는 주소 하나만 주면 된다

```
http://서버/api
```

이 주소가 **쓰는 법을 JSON 으로 돌려준다.** 토큰을 붙이면 지금 있는 폴더 목록까지 준다.
AI 에게 "이 주소를 먼저 읽고, 거기 적힌 대로 올려" 라고만 하면 된다.

### AI 에게 자료를 만들게 할 때

`/tokens` 페이지의 **「AI 에게 줄 자료 작성 규칙」** 을 복사해 먼저 준다. 접어 둔 칸이라
펼치지 않고 `복사` 만 눌러도 된다. 토큰과 무관하므로 올리지 않고 만들기만 할 때도 쓴다.

내용은 `lib/api-guide.js` 의 `authoringText()` **한 곳에만** 있다. 토큰 발급 문구와
`GET /api/authoring` 이 같은 글을 쓴다. 그 주소는 로그인 없이 열려 누구에게나 보낼 수 있다.

규칙이 다루는 것은 **실제로 막혔던 것들**이다.

- **파일 하나로** — 옆 파일 참조 금지, 이미지는 인라인 SVG 나 base64
- **인터넷 없이도 보이게** — 웹폰트(Google Fonts) 금지, CDN 은 없어도 안 깨지게
- **저장은 `localStorage` 만** — `sessionStorage`·`indexedDB`·쿠키는 동작하지 않는다
- **격리 전제** — `window.parent` 를 건드리지 않고, 바깥 링크는 `target="_blank"`

> **왜 필요한가.** 자료는 게시판 안의 격리된 틀에서 열린다. 게다가 **내려받아 파일로
> 직접 열면**(`file://`) 브라우저 보안 규칙이 더 엄해져 CDN 과 `fetch` 가 통째로 막힌다.
> 로컬에서 되던 것이 거기서 깨지는 이유가 이것이다. 바깥에 기대지 않는 파일일수록
> 어디서 열어도 똑같이 보인다.

### 폴더는 이름으로 지정한다

`folderPath` 에 `"제품 기획/2026 Q1"` 처럼 주면 **없는 폴더는 만들어 준다.**
id 를 알 필요가 없으므로 "어느 폴더에 넣어라" 는 지시가 그대로 먹는다.
이미 있으면 그걸 쓴다 — 같은 경로로 여러 번 올려도 폴더가 늘지 않는다.

```bash
curl -X POST http://서버/api/posts   -H "Authorization: Bearer deck_xxxxx"   -H "Content-Type: application/json"   -d '{"html":"<h1>안녕</h1>","filename":"a.html","folderPath":"제품 기획/2026 Q1"}'

# 자료의 상태를 직접 써 넣기
curl -X PUT http://서버/api/state/<글id>   -H "Authorization: Bearer deck_xxxxx"   -H "Content-Type: application/json"   -d '{"state":{"chk0":"1"}}'
```

토큰이 먹는 곳: `GET /api`, `GET /api/posts`, `POST /api/posts`, `PATCH /api/posts/:id`,
`POST /api/folders`, `GET|PUT /api/state/:id`.
계정·토큰 관리는 **브라우저 로그인만** 받는다 — 토큰으로 토큰을 만들 수는 없다.

## 발표자 노트

툴바의 `메모` 를 누르면 본문 아래에 메모 상자가 열린다. 치는 대로 자동 저장된다.

- **나만 본다.** 공유 주소(`/s/`, `/f/`)로는 나가지 않는다
- **발표 중에도 청중에게 안 보인다.** 전체화면은 본문에만 걸리고 메모는 그 바깥에 있다
- 메모만 고친 것은 목록의 날짜를 바꾸지 않는다 — "내용이 바뀐 글"로 보이면 곤란하다
- 한 글에 20,000자까지. `index.json` 에 같이 들어가므로 길이를 묶어 두었다

## 모바일 — 읽기 전용

좁은 화면(720px 이하)에서는 **읽기만** 된다. 목록과 본문을 반씩 나누지 않고 한 번에 하나만
보여주며, `←` 로 목록에 돌아온다. 폴더 공유 화면도 같다.

올리기·폴더 정리·제목 바꾸기 같은 **쓰기 수단은 감춰 둔다.** 손가락으로는 드래그 업로드도
폴더 정리도 제대로 되지 않아서, 있는 척하는 쪽이 더 나쁘다. 메모도 모바일에서는 읽기만 된다.

## 앱으로 설치하기 (PWA)

폰·PC 홈 화면에 **앱으로 설치**된다. 설치하면 주소창과 탭이 사라져서 발표할 때 화면이
그만큼 넓어지고, 앱 전환기에 브라우저와 따로 뜬다.

| 기기 | 설치하는 법 |
|---|---|
| 안드로이드 크롬 | 주소창 옆 **설치** 아이콘, 또는 메뉴 → 앱 설치 |
| 아이폰 사파리 | **공유** → 홈 화면에 추가 |
| PC 크롬·엣지 | 주소창 오른쪽 **설치** 아이콘 |

**HTTPS 가 아니면 안 된다.** 평문 http 로 열면 브라우저가 서비스 워커를 막아서 안드로이드·PC
설치가 안 뜬다 (아이폰의 "홈 화면에 추가"는 http 에서도 된다). 설치 아이콘이 안 보이면
주소부터 확인한다.

### 캐시하지 않는다 - 일부러 그렇게 뒀다

`public/sw.js` 는 설치 조건을 채우는 최소한의 워커이고 **아무것도 캐시하지 않는다.**
그래서 **오프라인에서는 열리지 않는다.**

캐시를 넣으면 "고쳤는데 옛 화면이 그대로 나온다"가 따라온다. 발표 자료는 수시로 바뀌고
서버도 도커로 갈아 끼우는 곳이라, 그 함정이 오프라인보다 비싸다고 봤다.

오프라인이 정말 필요해지면 **저장 브리지(`localStorage` → 서버)의 쓰기 큐부터** 만들어야
한다. 끊긴 동안 자료가 저장한 것을 쌓아 뒀다가 연결되면 보내는 장치다. 캐시는 그 다음이다.

### 설치한 앱에서 로그인을 다시 할 수 있다

iOS 는 홈 화면 앱의 쿠키를 사파리와 따로 두는 경우가 있다. 그러면 앱을 처음 열 때 로그인이
한 번 더 필요하다. 한 번만 하면 된다. 공유 링크(`/s/<token>`)는 로그인이 없으므로 영향 없다.

## 폴더 공유

폴더의 `···` → **폴더 공유 켜기**. 그 폴더와 **모든 하위 폴더**의 발표가 링크 하나로 열린다.
왼쪽에 목록, 오른쪽에 고른 발표가 뜨는 읽기 전용 화면이다.

**폴더 구조가 같이 간다.** 목록은 폴더별로 묶여 소제목(`2분기 / 상세`)이 붙고,
폴더 차례와 폴더 안 차례가 게시판에서 정한 그대로 나온다. 글이 없는 폴더는 나오지 않는다.

> 접히는 트리로는 만들지 않았다. 공유 화면은 **처음 보는 사람이 여는 자리**라 펴고 접게
> 시키면 그만큼 못 찾고, 좁은 화면에서 5단 들여쓰기는 읽히지 않는다. 깊이는 소제목의
> 경로로 눌러 담았다.

- **글 각자의 공유 설정과 무관하다.** 폴더를 공유했다는 건 그 안을 통째로 연다는 뜻이다
- **앞으로 그 폴더에 올리는 발표도 자동으로 포함된다.** 켤 때 확인 창이 이 점을 알린다
- 그래서 폴더 공유는 **기본이 꺼짐**이다 (글은 기본 켜짐)
- 공유 중인 폴더는 사이드바에 `공유` 배지가 붙는다
- 끄면 기존 주소가 바로 막히고, `새 공유 주소 발급`은 이미 보낸 주소를 폐기한다

CDN 을 쓰면 인터넷 없는 사내망에서 빈 화면이 되므로 파일째 넣어 두었다.
출처·버전·갱신 방법은 [`public/vendor/README.md`](public/vendor/README.md) 에 적어 두었다.

> **바깥으로 요청이 나가지 않는다.** 이 뷰어는 스타일·도형·스텐실을 `viewer.diagrams.net`
> 에서 받아오는 것이 기본값이라, 로드 전에 로컬 경로로 덮어쓴다. 실측으로 외부 요청 0건을
> 확인했다. **대가로 기본 도형 밖의 스텐실(AWS·Cisco 아이콘 등)은 그려지지 않는다** —
> 그런 그림은 draw.io 에서 SVG/PNG 로 내보내 올리면 된다.
>
> 뷰어 파일이 없으면(지웠거나 내려받기 전) 빈 화면 대신 "내려받아 draw.io 에서 여세요"
> 안내가 뜬다.

- SVG 는 스크립트를 품을 수 있어 **HTML 과 똑같이 격리**한다
- PNG 는 올릴 때 매직바이트를 확인한다 (PDF 와 같은 이유)

## PDF (`.pdf`)

이미 만들어진 PDF 는 변환하지 않고 **그대로 저장해 브라우저 내장 뷰어로** 띄운다.
쪽 넘김·확대·인쇄는 브라우저가 해 준다.

- 올릴 때 **첫 바이트가 `%PDF-` 인지 확인한다.** 확장자만 `.pdf` 인 파일은 거부한다
- base64 로 실어 보내므로 실제 한도는 `MAX_UPLOAD` 의 약 3/4 이다 (`50mb` → 약 37MB)
- 내려받으면 올린 PDF 원본이 그대로 나온다

> **PDF 에만 격리(sandbox)를 걸지 않는다.** 걸면 브라우저 내장 뷰어가 아예 뜨지 않는다(실측).
> PDF 는 이 페이지의 JS 로 실행되지 않고 브라우저가 자기 뷰어에서 열기 때문에 괜찮지만,
> **그 전제를 지키는 것이 위의 매직바이트 검사다.** 그 검사를 빼면 `.pdf` 로 이름 붙인
> HTML 이 격리 없이 실행된다. HTML·마크다운은 종전대로 격리된다.

## 올릴 수 있는 HTML

**단일 파일 self-contained HTML** 이 대상이다. AI 가 만드는 발표 자료가 거의 다 이 형태다.

- 되는 것 — 인라인 CSS/JS, Tailwind·Chart.js 같은 CDN 참조, reveal.js 슬라이드, 인라인 SVG, base64 이미지
- 안 되는 것 — `<img src="./img/a.png">` 처럼 **옆에 있는 파일을 참조**하는 HTML (이미지가 안 뜬다).
  이런 자료는 이미지를 base64 로 박아 한 파일로 만든 뒤 올린다
- 문자셋 선언이 없는 파일은 서버가 `<meta charset="utf-8">` 를 넣어 준다. 파일 자체는 UTF-8 이어야 한다

## 격리 — 올린 HTML 은 이 사이트를 건드리지 못한다

올라온 HTML 은 남이 쓴 코드다. 두 겹으로 막아 둔다.

1. 본문은 `sandbox` iframe 안에서 돈다 (`allow-same-origin` 없음)
2. 원본 주소 `/p/<id>` 는 응답 헤더에 `Content-Security-Policy: sandbox …` 를 실어 보낸다.
   **주소로 직접 열어도** 불투명 출처가 되어 이 사이트의 쿠키·`localStorage` 에 닿지 못한다

부작용 하나: 발표 자료가 `localStorage` 에 상태를 저장하려 하면 예외가 난다. 발표용으로는 문제가 없다.

### 우분투에 올릴 때 (계정 만들기까지)

```bash
# 1) 데이터 폴더를 미리 만들고 주인을 맞춘다.
#    컨테이너는 node 계정(uid 1000)으로 도는데, Docker 가 만든 폴더는 root 소유라
#    이 줄을 건너뛰면 "발표를 올릴 때" 쓰기에 실패한다.
mkdir -p data
sudo chown -R 1000:1000 data

# 2) 설정
cp .env.example .env
nano .env          # HOST_PORT 정도만. ADMIN_USER/PASSWORD 는 비워 둬도 된다

# 3) 띄우기
docker compose up -d --build

# 4) 계정 만들기 — 대화형이라 -it 가 필요하다
docker compose exec deck npm run adduser
```

4번이 물어보는 아이디·비밀번호가 로그인 정보다. 계정은 `data/users.json` 에 **해시로만**
저장되고 이미지 안에는 들어가지 않는다.

| 하려는 것 | 명령 |
|---|---|
| 계정 더 만들기 | `docker compose exec deck npm run adduser` |
| 계정 목록 보기 | 사이드바 아래 `계정` → 계정 목록 |
| 상태 보기 | `curl localhost:4300/api/health` → `{"ok":true,"accounts":N}` |

`.env` 에 `ADMIN_USER` / `ADMIN_PASSWORD` 를 채워 두면 **계정이 0개일 때 자동으로** 하나
만들어진다. 비밀번호가 `.env` 와 프로세스 환경에 남으므로, 쓸 거면 계정을 만든 뒤
그 두 줄을 지우는 편이 낫다.

> `.env` 는 `docker compose` 가 읽는다. `npm start` 로 직접 띄울 때는 `--env-file-if-exists`
> 를 붙여 둬서 역시 읽힌다 — 다만 **Node 20.6 미만에서는 무시된다.**

끝이다. `http://서버:4300` 으로 열린다.

| 명령 | 하는 일 |
|---|---|
| `docker compose logs -f` | 로그 보기 |
| `docker compose restart` | 재시작 |
| `docker compose up -d --build` | 코드를 고친 뒤 다시 말아 올리기 |
| `docker compose down` | 내리기 (**올린 발표는 안 지워진다**) |

올린 발표는 호스트의 `./data` 에 쌓인다. 컨테이너를 지우거나 이미지를 다시 말아도 남고,
**백업은 이 폴더만 뜨면 된다.**

### 데이터는 언제 날아가나

`docker-compose.yml` 은 **바인드 마운트**(`./data:/data`)를 쓴다. 호스트의 실제 폴더를
컨테이너 안에 끼워 넣는 방식이다. 그래서:

| 명령 | 올린 발표 |
|---|---|
| `docker compose down` | 남는다 |
| `docker compose down -v` | **남는다** — `-v` 는 *이름 있는 볼륨*만 지우고 바인드 마운트는 건드리지 않는다 |
| `docker rm` / 이미지 재빌드 | 남는다 |
| `rm -rf ./data` | **전부 사라진다** |
| 소스 폴더 삭제 / `git clean -xdf` | **전부 사라진다** (`data/` 가 소스 폴더 안에 있어서) |

즉 도커가 데이터를 지울 일은 없고, **위험한 건 호스트에서 폴더를 지우는 쪽**이다.
`data/` 를 소스 밖(`/srv/deck-data` 등)으로 빼면 그 반경이 줄어든다 — `docker-compose.yml`
의 `./data` 를 바꾸기만 하면 된다.

> 만약 `./data:/data` 를 `deck-data:/data`(이름 있는 볼륨)로 바꾼다면 그때는
> `down -v` 가 **데이터를 지운다.** 지금 설정에서는 해당 없다.

### 리눅스 서버 권한

컨테이너는 `node` 계정(uid 1000)으로 돈다. `./data` 에 쓰기가 안 되면
`sudo chown -R 1000:1000 ./data` 를 한 번 해 준다. Docker Desktop(Windows/macOS)은 그냥 된다.

## 사내 서버 배포 (도커 없이)

```ini
# /etc/systemd/system/deck.service
[Service]
WorkingDirectory=/srv/deck
Environment=PORT=4300
Environment=DATA_DIR=/srv/deck-data
Environment=SECURE_COOKIE=1
# 첫 계정은 `npm run adduser` 로 따로 만든다
ExecStart=/usr/bin/node server.js
Restart=always
```

앞단에 nginx 를 두고 **HTTPS 로 받는 것을 권한다.** 평문 HTTP 에서는 브라우저가 클립보드 API 를
막기 때문에 `링크 복사` 가 옛 방식으로 떨어지고, 전체화면 동작도 브라우저에 따라 제한될 수 있다.

> 이 저장소의 서버 설정·배포 설정·스크립트는 **그대로 운영에 올리지 말고** 사내 보안 기준에 맞춰
> 검토·테스트한 뒤 적용한다. 특히 사외 노출 여부와 접근 제어는 반드시 직접 확인할 것.

## API

로그인이 필요한 것은 **로그인 필요** 로 적었다. 나머지는 누구나 부를 수 있다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET` | `/api` | **쓰는 법 안내.** 토큰을 주면 폴더 목록까지 |
| `GET` | `/api/authoring` | 자료 만들 때 지킬 것 (글). 누구나 |
| `GET` | `/api/health` | 살아 있는지 + 계정 수 |
| `GET` | `/api/me` | 지금 로그인한 아이디 (없으면 `null`) |
| `POST` | `/api/login` | `{username, password}` |
| `POST` | `/api/logout` | |
| `GET` | `/s/:token` | 발표 하나 공유 화면 (읽기 전용) |
| `GET` | `/s/:token/raw` | 그 발표 본문 |
| `GET` | `/f/:token` | 폴더 공유 화면 (하위 전부, 읽기 전용) |
| `GET` | `/f/:token/:postId/raw` | 공유 폴더 안의 발표 본문 |
| `GET` | `/f/:token/:postId/download` | 공유 폴더 안의 원본 내려받기 |
| `GET` | `/api/posts` | 폴더 + 글 목록 — 로그인 필요 |
| `POST` | `/api/posts` | 등록 `{html, filename?, title?, folderPath?, folderId?}` — 로그인/토큰 |
| | | `.pdf`·`.png` 는 `html` 에 **base64** 를 넣는다 |
| | | `folderPath` 는 없는 폴더를 만들어 준다. `folderId` 보다 우선 |
| `PATCH` | `/api/posts/:id` | `{title?, html?, filename?, folderId?, shared?}` — 로그인 필요 |
| `POST` | `/api/posts/:id/share-token` | 공유 주소 재발급 — 로그인 필요 |
| `POST` | `/api/reorder` | 차례 저장 `{kind:'post'\|'folder', ids:[...]}` — 로그인/토큰 |
| `DELETE` | `/api/posts/:id` | 삭제 — 로그인 필요 |
| `POST` `PATCH` `DELETE` | `/api/folders[/:id]` | 생성·이름·부모·`shared` — 로그인 필요 |
| `POST` | `/api/folders/:id/share-token` | 폴더 공유 주소 재발급 — 로그인 필요 |
| `GET` `POST` | `/api/users` | 계정 목록·추가 — 로그인 필요 |
| `POST` | `/api/password` | `{current, next}` — 로그인 필요 |
| `GET` | `/p/:id` | 편집 화면용 본문 — 로그인 필요 |
| `GET` | `/download/:id` | 올린 원본 내려받기 — 로그인 필요 |
| `GET` `PUT` | `/api/state/:id` | 자료가 저장한 상태 — 로그인/토큰 |
| `GET` `POST` | `/api/tokens` | 토큰 목록·발급 `{label, days}` — **로그인만** |
| `DELETE` | `/api/tokens/:id` | 토큰 삭제 — **로그인만** |

`POST /api/posts` 의 `html` 은 **파일 내용**이고, 마크다운인지 HTML 인지는 `filename` 의
확장자로 가린다.
